# Правила для ИИ-агентов

1. Сначала читай `spec.md` и `docs/adr/`.
2. Модули: `backend` (вход API), `importer`, `dynamics`, `calls`, `ai`, `frontend`.
3. Допустимо: `frontend → backend → importer | dynamics | calls | ai → база`. Модули `importer`, `dynamics`, `calls` и `ai` не знают друг о друге.
4. `ai` только читает данные и ничего не меняет.
5. До нового кода найди готовую функцию.
6. Реальные файлы заказчика и персональные данные не кладём в репозиторий. Тестовые обезличенные файлы — только в `data/test/` и `data/templates/`.
7. Модель ИИ подключаем через интерфейс, чтобы её можно было заменить. Внешний API допустим, но только с обезличенными тестовыми данными.
   Слова «долг», «задолженность», «должник» не используем в коде для пользователя и в документах.
8. Срезы не перезаписываются. Повторная загрузка того же файла не создаёт дублей.
9. На каждое правило динамики есть автотест в `backend/` (тесты лежат рядом с кодом).
10. Решение вне ADR: сначала вопрос Александру (техлид).
11. Одна задача = один небольшой PR. В названии ветки и PR — номер задачи из YouGile, например `aleksandr/SP-19-schema-db`.
12. Не хватает данных или правило неясно: остановись и спроси, не выдумывай.
