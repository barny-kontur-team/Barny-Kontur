# Barny-Kontur

Команда «Барни»: сервис контроля передачи оригиналов документов корпоративными клиентами (кейс Контур КЦР).
Интенсив «Лаборатория ИИ-решений», Phoenix Education × Университет «Дубна». Заказчик — Вера Вейн, АО «СКБ Контур».

## О проекте

Клиенты КЦР должны передавать в архив оригиналы заявлений и листов ознакомления. Если не передали — у клиента **долг**.
Сейчас долги ведут в нескольких Excel-файлах, срезы сравнивают вручную, история звонков теряется.

Мы делаем веб-сервис, который:

- загружает Excel-срезы без дублей;
- хранит историю долга и сам считает динамику: новый, уменьшается, закрыт, повторный, хронический;
- показывает таблицу клиентов с фильтрами и поиск по коду КЦР и ИНН;
- даёт оператору «взять клиента в работу» (без конфликтов), записать звонок и следующий контакт;
- собирает список «сегодня нужно»;
- показывает карточку клиента со всей историей;
- работает с двумя ролями: администратор и оператор.

Вне рамки: дашборды, отправка писем, интеграции с системами Контура. Данные только тестовые.
Импорт Excel делаем отдельным модулем, чтобы позже заменить его на API.

## Как пользуемся трекером

1. **Все задачи — в [Issues](../../issues).** Одна задача — одна карточка.
2. **Новая задача:** Issues → New issue → выбрать шаблон («Задача», «Вопрос заказчику» или «Баг»).
3. **Взял задачу — назначь себя** (Assignees) и перетащи на доске в «В работе».
4. **Сделал — закрой задачу** и оставь комментарий со ссылкой на результат.
5. **Застрял — напиши в комментарии** и упомяни капитана.
6. **Метки:**
   - `роль: …` — кто отвечает;
   - `приоритет: высокий / средний / низкий`;
   - `тип: задача / документ / вопрос заказчику / баг`.
7. **Этап (Milestone)** — к какой сдаче относится задача.
8. **Доска:** вкладка [Projects](../../projects), колонки «Сделать → В работе → Готово».
