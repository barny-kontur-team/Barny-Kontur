# Barny-Kontur

Команда «Барни»: сервис контроля передачи оригиналов документов корпоративными клиентами (кейс Контур КЦР).
Интенсив «Лаборатория ИИ-решений», Phoenix Education × Университет «Дубна».

## О проекте

Клиенты КЦР должны передавать в архив оригиналы заявлений и листов ознакомления. Если не передали — клиенту нужно напомнить.
Сейчас непереданные документы ведут в Excel, срезы сравнивают вручную, история звонков теряется.

Сервис:

- загружает Excel-срезы без дублей;
- хранит историю срезов и сам считает динамику: впервые, уменьшается, не меняется или растёт, все переданы, повторное появление; отдельно отмечает «новичок» и «хронический»;
- показывает таблицу клиентов с фильтрами и поиск по коду КЦР и ИНН;
- даёт оператору взять клиента в работу (без конфликтов), записать звонок и следующий контакт;
- собирает список «сегодня нужно»;
- показывает карточку клиента со всей историей;
- работает с ролями «администратор» и «оператор».

Данные только тестовые. Импорт Excel — отдельный модуль, чтобы позже заменить его на API.

## Структура

| Папка | Что лежит |
|---|---|
| `backend/` | Сервер: логика, база данных, импорт Excel, тесты |
| `frontend/` | Интерфейс |
| `data/templates/` | Шаблоны Excel с описанием колонок |
| `data/test/` | Тестовые срезы и контрольные примеры |
| `docs/` | Бриф, модель данных, как заменить Excel на API, отчёт и презентация |

## Главные документы

- `spec.md` — что строим.
- `AGENTS.md` — правила для ИИ-агентов.
- `docs/adr/` — принятые решения (ADR).
- `docs/c4.md` — схема C4: модули и связи.

Внутри `backend/` модули лежат в папках `importer/` (загрузка Excel), `dynamics/` (расчёт динамики) и `ai/` (ИИ-помощник, только чтение).

## Как работаем с репозиторием

1. Не пушим напрямую в `main`.
2. Для каждой задачи — своя ветка: `имя/коротко-о-задаче`, например `andrey/import-excel`.
3. Готово — открываем Pull Request в `main`, его смотрит техлид.
4. Задачи и их статусы ведём в YouGile, здесь только код и материалы.
