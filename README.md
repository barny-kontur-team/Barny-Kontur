# Barny-Kontur

Команда «Барни»: сервис контроля передачи оригиналов документов корпоративными клиентами (кейс Контур КЦР).
Интенсив «Лаборатория ИИ-решений», Phoenix Education × Университет «Дубна».

## О проекте

Клиенты КЦР должны передавать в архив оригиналы заявлений и листов ознакомления. Если не передали — клиенту нужно напомнить.
Сейчас непереданные документы ведут в Excel, срезы сравнивают вручную, история звонков теряется.

Сервис:

- загружает Excel-срезы без дублей;
- хранит историю срезов и сам считает динамику: впервые, уменьшается, не меняется или растёт, все переданы, повторное появление; отдельно отмечает «новичок» и «хронический»;
- показывает таблицу клиентов с фильтрами и поиск по коду КЦР и ИНН;
- даёт оператору взять клиента в работу (без конфликтов), записать звонок и срок, который назвал клиент;
- собирает список «сегодня нужно»;
- показывает карточку клиента со всей историей;
- работает с ролями «администратор» и «оператор».

Данные только тестовые. Импорт Excel — отдельный модуль, чтобы позже заменить его на API.

## Структура

| Папка | Что лежит |
|---|---|
| `backend/` | Сервер: логика, база данных, импорт Excel, тесты |
| `frontend/` | Интерфейс |
| `data/templates/` | Шаблоны Excel с описанием колонок |
| `data/test/` | Тестовые срезы и контрольные примеры |
| `scripts/` | Скрипты проверок гипотез (H-01, H-02, H-08) и генерации тестовых файлов |
| `docs/` | Бриф, модель данных, как заменить Excel на API, отчёт и презентация |

## Главные документы

- `spec.md` — что строим.
- `AGENTS.md` — правила для ИИ-агентов.
- `docs/adr/` — принятые решения (ADR).
- `docs/c4.md` — схема C4: модули и связи.

Внутри `backend/` модули лежат в папках `importer/` (загрузка Excel), `dynamics/` (расчёт динамики), `calls/` (звонки, этапы, претензии) и `ai/` (ИИ-помощник, только чтение).

## Как запустить

Стек выбран (ADR-0001): FastAPI + PostgreSQL, запуск через Docker Compose.

```bash
cp .env.example .env
docker compose up --build
```

Поднимаются база и сервер. Проверка: http://localhost:8000/health —
`{"status":"ok","db":"ok"}`. Документация API: http://localhost:8000/docs.

Запуск без Docker (для разработки):

```bash
cd backend
python -m pip install -r requirements-dev.txt
python -m uvicorn main:app --reload   # база по умолчанию — локальный sqlite
```

Тесты: `cd backend && python -m pytest tests/`

Скрипты проверок гипотез: см. `scripts/h02/README.md`.

Что уже работает, а что заглушки: поднимаются сервер, база и схема из 9 таблиц
(`backend/models.py`); модули `importer`, `dynamics`, `calls`, `ai` отвечают 501 —
рабочие функции в спринте 3. Интерфейс добавит Артём (`frontend/`).

## Как работаем с репозиторием

1. Не пушим напрямую в `main`.
2. Для каждой задачи — своя ветка: `имя/номер-задачи-коротко`, например `andrey/SP-10-docker`. Номер задачи берём из YouGile.
3. Готово — открываем Pull Request в `main` (шаблон заполнится сам), его смотрит техлид.
4. Задачи и их статусы ведём в YouGile, здесь только код и материалы.
