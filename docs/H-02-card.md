# Карточка H-02: расчёт динамики в сервисе

**Решение по новичку (17.11.2026):** `is_novice` хранится как признак клиента на дату среза независимо от количества непереданных документов. Метка `show_novice_badge` отображается только если `missing_documents > 0`. Это первый из двух предложенных вариантов; конвенция согласована с ADR-0002.

**Критерии:** контрольная книга DS-02 — 86 строк; ручная разметка — 51 клиент и 187 валидных записей; негативные Excel-файлы E01–E12 должны получить понятную ошибку; история хранится по срезам.

**Проверка API:** загрузить клиентов, последовательно S001–S006 с датой и кварталом, GET `/api/clients/{client_id}/dynamics` должен вернуть все снимки по возрастанию дат. При повторной загрузке одинакового среза ожидается 409.

**Ограничение:** этап работы `is_chronic` в текущем MVP берётся из текущего активного `work_cycle`; для исторически точного пересчёта при изменении этапа нужно хранить историю этапов на дату среза.
