# H-02 — как проверить реализацию

## Что реализовано

- **ADR-0002**: `is_novice` сохраняется независимо от количества непереданных документов; метка `show_novice_badge` видна только при ненулевом количестве.
- **Валидация**: `python scripts/h02/check_negative_imports.py` — 12 отрицательных сценариев и таблица причин в `docs/H-02-negative-checklist.md`.
- **Расчёт**: `backend/dynamics/features.py` — сохранённая исходная логика модели Б из `scripts/h02/features.py`, `backend/dynamics/service.py` — пересчёт по истории при импорте.
- **Импорт**: `POST /api/imports/clients` и `POST /api/imports/snapshots` принимают Excel. Для второго требуется форма `reporting_period` и `snapshot_date` (`YYYY-MM-DD`). Период — например `I кв. 2026`. Повторный срез на ту же дату отклоняется (409).
- **API**: `GET /api/clients/{client_id}/dynamics` возвращает упорядоченный массив `history` с историей снимков, тремя признаками и бейджем новичка.
- **Тесты**: `backend/tests/test_h02_dynamics.py`, в том числе 86 строк DS-02, 51 размеченный клиент / 187 валидных строк, 12 ошибочных файлов, API и сохранение истории.

## Команды для локального запуска

```bash
python -m pip install -r backend/requirements-dev.txt -r scripts/requirements.txt
PYTHONPATH=backend pytest -q backend/tests
python scripts/h02/check_negative_imports.py
PYTHONPATH=backend uvicorn main:app --app-dir backend --reload
```

Swagger API: `http://127.0.0.1:8000/docs`. Для загрузки сначала используйте `00_Клиенты.xlsx`, затем S001–S006 по порядку с датами, указанными в имени файлов.

## Ограничения

- Импорт на данный момент реализован как минимальный строгий режим: при ошибках в строках файл отклоняется целиком. Согласованное отдельно правило частичной загрузки для неизвестного идентификатора («пропустить строку, сохранить остальные») **ещё не реализовано**; потребуется доработка перед приёмкой общего H-01.
- Для показателя `is_chronic` сейчас применяется текущий активный этап работы. Исторически достоверный этап на дату каждого среза потребует таблицу истории этапов. Предыдущие числовые значения срезов сохраняются неизменными.
- Данные из архива имеют обезличенный тестовый характер; запуск на продуктивной базе не проводился.
