# ADR-0001. Модульный монолит с отдельным модулем импорта

1. **Статус.** Предложено, ждёт подтверждения техлида (Александр).
2. **Контекст.** Команда из 7 человек, 4 недели разработки, один сервер, около 6 тысяч клиентов, срез около 3 тысяч строк.
3. **Качества числом.** (а) Данные не теряются: срезы не перезаписываются, повторная загрузка даёт 0 дублей, копия БД раз в сутки. (б) Скорость: от загрузки среза до списка не больше 15 минут, таблица открывается не дольше 5 секунд на 6 тысячах клиентов. (в) Простота: запуск одной командой, модули ходят друг к другу только по схеме C4.
4. **Решение.** Одно приложение с модулями: импорт, динамика, звонки, ИИ-помощник (только чтение, модель за интерфейсом и заменяема). Запуск через Docker Compose.
5. **Альтернативы.** Микросервисы (долго и сложно для команды), один общий скрипт (тяжело менять и тестировать).
6. **Последствия.** Просто запускать и показывать на демо. Если нагрузка вырастет, модули можно вынести в сервисы позже.
7. **Проверка.** Два тестовых среза без ручных правок на 95% (H-01), время до списка не больше 15 минут (H-03), тот же файл дважды даёт 0 дублей.
