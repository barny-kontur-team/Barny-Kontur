# frontend

Интерфейс сервиса (React) — сюда заходит Артём.

Договорённости по скелету:

- Запуск через общий `docker compose up` — добавить сервис в `docker-compose.yml`
  (порт 5173 или 80).
- Бэкенд: http://localhost:8000, документация API — `/docs`.
- Экраны (spec.md): таблица клиентов с фильтрами, карточка клиента с историей,
  импорт с отчётом об ошибках, роли администратор/оператор.
- По H-08 берём вариант А: этап, ответственный и обещанный срок рядом с цифрами
  нового среза; добавляем пометку «Новичок», «срок наступил / не наступил»,
  отдельный статус «работа завершена», заметную метку «Не работать».
- Слова «долг», «задолженность», «должник» не используем — «непереданные документы».
