# Фронтенд Barny‑Kontur

React-интерфейс по финальным экранам Pixso и сценариям администратора и оператора.

## Запуск

Из корня репозитория:

```sh
docker compose up --build
```

Интерфейс: http://localhost:5173. API: http://localhost:8000/docs.

Для запуска без Docker используйте Node.js 22.12 или новее:

```sh
cd frontend
npm ci
npm run dev
```

## Демонстрация

На экране входа выберите роль и нажмите «Подставить демоданные», затем «Войти».
Администратор — `admin@example.test`, оператор — `operator@example.test`,
пароль обеих ролей — `demo1234`. Для смены роли выйдите из аккаунта без
перезагрузки страницы, чтобы продолжить работу с тем же пулом клиентов.

Дата демонстрации — 24.10.2026. На экране загрузки доступны два примера:
«С ошибками строк» показывает частичный импорт, «С дубликатом» — отклонение
всего файла. Также можно выбрать обезличенный .xlsx с кодами КЦР из демореестра.

Данные хранятся в памяти вкладки и сбрасываются после перезагрузки.
Вход проверяет демонстрационные учётные записи локально. Предпросмотр читает
Excel в браузере, а ИИ-помощник формирует ответы локально по тестовым данным.
Интерфейс пока работает автономно от FastAPI. Логика и набор демоданных
собраны в `src/demo.js`, чтобы их можно было заменить вызовами API.
