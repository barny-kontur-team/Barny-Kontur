# Фронтенд Barny‑Kontur

React-интерфейс по финальным экранам Pixso и сценариям администратора и оператора.

## Запуск

Из корня репозитория:

```sh
docker compose up -d --build
docker compose exec api python -m seed
```

Интерфейс: http://localhost:5173. API: http://localhost:8000/docs.

Для запуска без Docker используйте Node.js 22.12 или новее:

```sh
cd frontend
npm ci
npm run dev
```

## Демонстрация

Команда `seed` добавляет в локальную БД 20 контрольных клиентов H-08
с историей срезов и звонков. Её можно запускать повторно. Если тестовый код КЦР
занят другой записью, команда остановится и выведет конфликтующие коды.

На экране входа выберите роль и нажмите «Подставить демоданные», затем «Войти».
Общий демопароль — `demo1234`. Администратор — `admin@example.test`.
Операторы — `operator@example.test`, `operator2@example.test`, `operator3@example.test`.

В «Загрузках» можно импортировать справочник клиентов или срез. Для реального
файла проверку и результат возвращает API. При ошибке сервер отклоняет файл
целиком. Встроенные примеры частичного импорта и дубликата выполняются только
на экране загрузки.

Срезы, назначения и звонки сохраняются в БД. Проверка пароля, ИИ-сводки,
претензии и следующая дата контакта демонстрационные. Введённые претензии и
даты контактов хранятся до перезагрузки страницы.
