# scripts

Скрипты, которые не входят в сам сервис:

- проверки гипотез: H-01 (сопоставление клиентов между срезами), H-02 (расчёт динамики), H-08 (новый срез не затирает историю);
- генерация тестовых Excel-файлов по кейсам.

Работают только с обезличенными файлами из `data/test/`. Результаты проверок записываем в карточки гипотез.
