# scripts/h02 — скрипты проверки гипотезы H-02

Гипотеза H-02 («модель Б»: три признака на каждый срез + дата первого появления)
подтверждена 05.11.2026. Скрипты — рабочий инструмент проверки, правила из них
переносятся в `backend/dynamics/` (спринт 3).

| Файл | Что делает |
|---|---|
| `features.py` | Расчёт признаков (модель Б): изменение между срезами, «новичок», «хронический», итоговая категория, пул обзвона. Правила — в докстринге модуля. |
| `run_h02_check.py` | Полная проверка H-02: матрица сочетаний (модель А vs модель Б), восстановление истории, сверка с «Оракулом динамики» из контрольной книги, время пересчёта на срезе 3 000 строк. |
| `run_h02_markup.py` | Сверка скрипта с ручной разметкой 50 клиентов (51 клиент, 187 строк). |

## Запуск

```bash
python -m pip install -r scripts/requirements.txt

python scripts/h02/run_h02_check.py     # сверка с контрольной книгой (DS-02)
python scripts/h02/run_h02_markup.py    # сверка с ручной разметкой
```

Данные берутся из `data/test/h02/` (обезличенный синтетический набор DS-02).

Результаты пишутся в `scripts/h02/out/` (в git не попадает): отчёты .md и .xlsx
с построчной сверкой и матрицей сочетаний.

## Ожидаемый результат

- контрольная книга: 86/86 строк совпадают с «Оракулом динамики», восстановление истории 211/211;
- разметка: 187/187 строк (в конвенции отображения разметки), 51/51 клиентов — критерий H-02 «≥ 49 из 50» выполнен.

Единственное известное расхождение — конвенция флага «новичок» при not=0
(скрипт хранит новичка как признак клиента, разметка показывает бейдж только
при not>0) — зафиксировано в карточке H-02.
