# Спецификация (коротко)

**Задача.** Администратор загружает срезы из Excel и вместо 15–20 часов ручной работы получает по каждому клиенту динамику непереданных документов и список на обзвон. Оператор берёт клиента в работу и записывает звонок. Вся история видна в одной карточке.

**Пользователи.** Администратор (2–3 человека), оператор (до 10 человек).

**Что делаем (MVP).**
- Импорт клиентов и срезов из Excel без дублей, срезы не перезаписываются.
- Динамика между срезами: все переданы, впервые, уменьшается, не меняется или растёт, повторное появление. Отдельно, независимо от динамики: признак клиента «новичок» и признак «ситуация сохраняется несколько кварталов» (хронический).
- Таблица с фильтрами, поиск по коду КЦР и ИНН, список на обзвон, «сегодня нужно».
- Оператор видит весь пул клиентов, переданных в обзвон, и может перехватить клиента у коллеги, сменив ответственного. Остальная база ему не нужна.
- Событие «звонок»: срок, который назвал клиент, обязателен, дата следующего звонка — нет (её определяет новый срез). Можно добавить событие с фактической датой, чтобы перенести старый контекст.
- Карточка клиента с историей.
- Исправление ошибки: отмена последней загрузки среза.
- Претензии и санкции, роли и вход по паролю.
- ИИ-помощник, только чтение, не меняет данные. Оператору: сводка по клиенту перед звонком. Администратору: выборка клиентов по запросу словами. Если данных не хватает, помощник так и говорит. Модель подключена через интерфейс, чтобы её можно было заменить (сейчас допустим внешний API, позже — внутренняя модель Контура).

**Не делаем.** Дашборды, шаблоны и отправку писем, интеграции с системами Контура, двухфакторную авторизацию, автоматическую отправку претензий, автоматические переходы между этапами.

**Правила.** Срез на 20-е число. Срез сравнивается со срезом. Хронический — 2 квартала подряд. Порог 5% настраивается, «новичков» это правило не касается. По сертификату 2 документа. Код КЦР уникален, у одного ИНН может быть несколько кодов, дубль кода в файле — ошибка. «Всего документов» за период фиксируется при первой загрузке и дальше не меняется.

**Слова.** Не используем «долг», «задолженность», «должник» ни в интерфейсе, ни в документах. Говорим «непереданные документы».

**Ограничения.** Только тестовые обезличенные данные. Демо — 19.12.2026.

**Проверяем гипотезами** (карта гипотез, 11 штук). Первыми: H-01 — клиенты сопоставляются между срезами, H-02 — динамика считается верно, H-08 — новый срез не затирает историю. Дальше: H-03 — ИИ-помощник, H-04 — время подготовки списка (не больше 15 минут), H-09 — два оператора и один клиент, H-10 — права доступа, H-11 — выбор архитектуры.
