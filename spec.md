# Спецификация (коротко)

**Задача.** Администратор загружает срезы из Excel и вместо 15–20 часов ручной работы получает по каждому клиенту динамику долга и список на обзвон. Оператор берёт клиента в работу и записывает звонок. Вся история видна в одной карточке.

**Пользователи.** Администратор (2–3 человека), оператор (до 10 человек).

**Что делаем (MVP).**
- Импорт клиентов и срезов из Excel без дублей, срезы не перезаписываются.
- Динамика по 7 категориям: все переданы, впервые, уменьшается, не меняется или растёт, повторное, сохраняется несколько кварталов, новичок.
- Таблица с фильтрами, поиск по коду КЦР и ИНН, список на обзвон, «сегодня нужно».
- «Взять в работу» без конфликтов, событие «звонок», карточка клиента с историей.
- Претензии и санкции, роли и вход по паролю.
- ИИ-помощник: сводка по клиенту и ответы по данным, только чтение.

**Не делаем.** Дашборды, отправку писем, интеграции с системами Контура, двухфакторную авторизацию, автоматическую отправку претензий.

**Правила.** Срез на 20-е число. Срез сравнивается со срезом. Хронический — 2 квартала подряд. Порог 5% настраивается, «новичков» это правило не касается. По сертификату 2 документа. Код КЦР уникален, дубль в файле — ошибка.

**Ограничения.** Только тестовые обезличенные данные. Демо — 19.12.2026.

**Проверяем гипотезами** (карта гипотез): H-01 данные, H-02 динамика, H-03 время подготовки списка.
